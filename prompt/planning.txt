[Task]
할 일 목록 앱의 핵심 기능을 Clean Architecture 방식으로 구현해줘. 

[비즈니스 요구사항]
사용자가 할 수 있는 것 : 
1. addTodo: 새 할일 추가
2. getTodos：전체 목록 조회
3. toggleTodo: 완료 상태 토글
4. deleteTodo: 할 일 삭제
5. updateTodo: 할 일 수정

［데이터 구조］
interface Todo  { 
	id: string;
	title：string;
	completed: boolean;
	createdAt: Date;
}

[제약 조건]
- 로그인한 사용자만 사용 가능
- 제목 : 5~100자
- 본문 : 10~500자.


[기술 스택]
- Typescript
- Next.js 최신버전 사용 (npx create-next-app@latest .) 실행
- Shadcn UI
- MDX 컨텐츠 관리

[출력]
- 기획한 클린 아키텍처 폴더 구조를 출력해줘.
